# Roadmap

This release intentionally stops before becoming a desktop framework.

Potential future additions:

- wallpaper selector (currently intentionally omitted)
- dynamic wallpaper → palette extraction
- theme selector
- battery/power-profile module
- GPU temperature/utilisation module
- idle OSD
- media player module
- monitor profiles
- host-specific overrides
- optional Starship shell configuration
- optional GTK/Qt theme synchronization

The guiding constraint: each new feature should have one obvious source file and one obvious runtime dependency.
